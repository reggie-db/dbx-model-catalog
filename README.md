# dbx-model-catalog

A normalized catalog that matches model metadata and benchmark results from:

- [models.dev](https://models.dev/)
- [modelparams.dev](https://modelparams.dev/)
- [Arena Leaderboard](https://arena.ai/leaderboard)
- Databricks Foundation Model APIs

The planned workflow will refresh weekly, reconcile model identities across
sources, and publish a queryable database of normalized model capabilities,
parameters, rankings, availability, and Databricks endpoint mappings.

## Status

Repository initialized. Automated ingestion, matching, and weekly publishing
will be added next.
